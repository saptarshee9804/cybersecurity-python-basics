# Cybersecurity Python Basics

A beginner-friendly collection of Python exercises created while learning programming and cybersecurity.

## Current Project

### Password Checker
- Checks password length.
- Checks for uppercase and lowercase letters.
- Checks for digits and special characters.
- Provides a basic feedback category.

## Technologies
- Python 3
- Git and GitHub

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   `python password_checker.py`

## Learning Goals
- Practise Python functions and conditional statements.
- Learn to organize source code.
- Understand commits and repository management.

## Limitations
This exercise checks basic characteristics only. It does not measure real-world password security or check whether a password has been exposed.
